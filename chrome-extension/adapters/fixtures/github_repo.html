mono-agent

A workflow engine that runs where your data is: one binary, no daemon fleet, no cloud round trip.

Install

go install github.com/monoes/mono-agent/cmd/monoagentcli@latest

Why

  • Your credentials never leave the machine.
  • A workflow is a file you can diff.
