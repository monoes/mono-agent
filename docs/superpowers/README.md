# Superpowers — historical design records

The plans and specs in this directory are historical design records from
earlier development phases, kept for reference only. Some approaches
described here — stealth/anti-detection measures and astroturf-style
engagement actions — were removed from the product; see
[CHANGELOG.md](../../CHANGELOG.md). Current behavior is documented in
[README.md](../../README.md) and [docs/USAGE_POLICY.md](../USAGE_POLICY.md).
